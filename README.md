# ДЛЯ РАЗРАБОТЧИКОВ:

Перед началом работы:

npm ci

# Проверить все файлы на ошибки

npm run lint

# Автоматически исправить ошибки (где возможно)

npm run lint:fix

# Отформатировать все файлы в проекте

npm run format

# Проверить все CSS файлы

npm run stylelint

# Автоматически исправить ошибки

npm run stylelint:fix

# 4. Особенности проекта

# 4.1. Технические особенности

Полная типизация на TypeScript — все компоненты и функции имеют строгую типизацию
Модульная архитектура — легко масштабировать и поддерживать
Feature-Sliced Design — четкое разделение ответственности между слоями
Современный инструментарий — Vite для быстрой сборки
Качество кода — настроены ESLint, Prettier, Stylelint
Адаптивная верстка — сайт корректно отображается на всех устройствах
SEO-оптимизация — возможность добавления мета-тегов и семантической верстки

# 4.2. Бизнес-особенности

Персональный бренд врача — сайт работает на репутацию и доверие
Мобильная версия — пациенты могут записаться с телефона
Юридическая защита — размещены все необходимые документы
Социальное доказательство — блок с отзывами повышает доверие
Локальный SEO — указан адрес и контакты для поиска в регионе

# 5. Возможности для развития

Интеграция с CRM для управления записями пациентов
Онлайн-оплата консультаций и дополнительных материалов
Личный кабинет пациента с историей обращений и возможность добавлять и сохранять полезные материталы
Интеграция с Telegram для уведомлений о записи
Блог врача с полезными статьями, вебинарами
