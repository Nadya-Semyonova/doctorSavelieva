# ДЛЯ РАЗРАБОТЧИКОВ:

# Проверить все файлы на ошибки

# Автоматически исправить ошибки (где возможно)

# Проверить все CSS файлы

npm run stylelint

# Автоматически исправить ошибки

npm run stylelint:fix

# 4. Особенности проекта

# 4.1. Технические особенности

- Полная типизация на TypeScript — строгая типизация всех компонентов и функций.
- Модульная архитектура (FSD) — четкое разделение ответственности между слоями, легкое масштабирование.
- Современный инструментарий — Vite для мгновенного HMR и быстрой финальной сборки.
- Качество кода — настроены ESLint, Prettier, Stylelint для единообразия.
- Адаптивная верстка — корректное отображение на всех устройствах.
- SEO-оптимизация — семантическая верстка, мета-теги, Open Graph, JSON-LD микроразметка (Schema.org).

# 4.2. Бизнес-особенности

- Персональный бренд — сайт работает на репутацию, доверие и экспертность врача.
- Удобная запись — пациенты могут оставить заявку или записаться на онлайн-консультацию с любого устройства.
- Юридическая защита — размещены договор-оферта и политика конфиденциальности (соответствие 152-ФЗ).
- Социальное доказательство — блок с отзывами повышает доверие новых пациентов.
- Локальное SEO — микроразметка адреса и контактов для лучшего ранжирования в регионе.
- Интеграция с Telegram-ботом для автоматических уведомлений о записи и напоминаний о приеме.

# 5. Возможности для развития

- Онлайн-оплата консультаций и дополнительных материалов
- Личный кабинет пациента с историей обращений и возможность добавлять и сохранять полезные материталы
- Блог врача с полезными статьями, вебинарами
